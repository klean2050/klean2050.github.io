# Kleanthis Avramidis - Overleaf CV

Upload `main.tex` and `res.cls` to an Overleaf project. Set `main.tex` as the main
file and choose pdfLaTeX. All other dependencies are standard TeX packages; no
images, fonts or bibliography files need uploading.

This adapts the user's supplied res-class CV template. Updated November 5, 2026:
research framing, full publication citations, teaching order, and all eight
confirmed mentees are carried over from the website. Earlier user corrections to
mentoring years and destinations override older entries in the pasted source.

The template attribution is retained at the top of main.tex. The original res.cls
copyright and reuse notice are retained in that file. Do not remove them.

Publications are kept in unbroken minipages; explicit page breaks balance the
current 22-paper selection. Recheck these breaks when changing the list.
